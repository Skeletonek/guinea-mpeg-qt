# Contributing guidelines

## Main git hosting platform

New pull requests or issues can be published on all mirrors where the project is present, but do mind that [gitlab.com](https://gitlab.com/Skeletonek/guinea-mpeg-qt/) is considered to be the main hosting platform for this project. 
Contributions done on other mirrors, such as github.com, may get ignored.

## LLM usage

### Code Contributions

AI-generated and AI-assisted code contributions are allowed, but quality testing and reviews must be done by a human to be approved.

### Discussion & Communication

Using AI tools to write comments, replies, or open issues/Pull Requests is prohibited, and such interactions will be automatically closed or ignored
